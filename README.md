# Legal

Privacy policies and terms for games made by TBCore.

Published with GitHub Pages, so every document has a permanent public URL that
can be pasted straight into a Google Play listing.

```
index.html                              landing page, lists every game
scrap-to-stars/privacy-policy.html      Scrap to Stars (dk.scraptostars)
```

## Adding a game

Create a folder named after the game, put its documents inside, and add a card
to `index.html`. Keep the same wording where the facts are the same — if two
games behave differently with data, the policies must say so differently.

## Publishing

Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

The repository must stay public. GitHub Pages on a private repository requires
a paid plan, and the URL has to be reachable by anyone for Play to accept it.
